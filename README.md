# Project - 5   OOP Wrapper

### Introduction
Employee Management System is a Python project developed to practice and strengthen important Object-Oriented Programming (OOP) concepts.

It allows users to create and manage Person, Employee, and Manager objects through a menu-driven program. The project demonstrates class creation, constructors, inheritance, encapsulation, getter and setter methods, method overriding, and displaying object details.

### Features

- Create a Person
- Create an Employee
- Create a Manager
- Manager inherits from Employee
- Store and display Person details
- Store and display Employee details
- Store and display Manager details
- Use private attributes for Employee ID and Salary
- Use getter methods to access private data
- Use setter methods to update private data
- Use constructors (`__init__`)
- Use inheritance with `super()`
- Override the `display()` method
- Menu-driven program using `match-case`
- Nested menu for showing Person, Employee, and Manager details
- Input validation using conditional statements
